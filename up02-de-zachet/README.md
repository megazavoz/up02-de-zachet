Каталог электроники — «ЭлектроМир»

Десктопное приложение для автоматизации учёта товаров и заказов в магазине электроники. 
Разработано в рамках демонстрационного экзамена (ДЭ) по компетенции «Программные решения для бизнеса».

 Реализованный функционал
Проект включает в себя выполнение **Задания 2** и **Задания 4**:

- **Каталог товаров:** динамическая загрузка из БД, вывод карточек с изображением, характеристиками и ценой.
- **Подсветка остатков:** товары с количеством ≤ 3 подсвечиваются красным цветом (`#ff8080`).
- **Алгоритм скидок:** автоматический расчёт скидки 25% для товаров, которые не заказывали в прошлом месяце.
- **Оформление заказа:** выбор товара, валидация введённого количества, проверка наличия на складе.
- **Управление заказами (CRUD):** 
  - Просмотр списка всех заказов (через JOIN таблиц).
  - Просмотр детального состава заказа с расчётом итоговой суммы.
  - Изменение даты заказа (доступно только Администратору).
  - Удаление позиций из заказа и полное удаление заказа с возвратом остатков на склад.
- **Разграничение прав:** роли Клиент, Менеджер и Администратор (у Админа есть права на редактирование).

 Используемые технологии
- **Язык:** Python 3.11+
- **GUI:** Tkinter (стандартная библиотека)
- **База данных:** SQLite3 (транзакции, JOIN, агрегатные функции)
- **Работа с изображениями:** Pillow (PIL)
